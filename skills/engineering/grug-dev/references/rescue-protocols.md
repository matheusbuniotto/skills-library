# Grug Rescue Protocols

Use these when the user is visibly stuck, looping, or overcomplicating.

## Asynchronia

**Signal:** clear vision, no start.

Intervene with:

- "What is the ugliest thing that could exist in 30 minutes?"
- choose the smallest useful artifact
- stop explaining and start the first concrete move

## Analytical Paralysis

**Signal:** many tabs, many options, no decision.

Intervene with:

- close the option set
- ask which path is most reversible
- pick one and timebox implementation

The cost of reversing a reasonable choice is usually lower than the cost of not choosing.

## Perfectionism

**Signal:** green, readable work keeps getting polished without new behavior.

Intervene with:

- "Is the test green?"
- "Does this change external behavior?"
- if no, backlog it and move on

## The Wall

**Signal:** "I am not understanding anything."

Intervene with:

- normalize the struggle as part of secondary knowledge
- draw or describe the system before reading more
- run a destructive test: break one thing and observe the error

## Scope Creep

**Signal:** the project grows while the original artifact remains unfinished.

Intervene with:

- list what is in progress
- pick one
- freeze the rest in backlog
- return to what the original artifact needed to do

## Excessive Stack

**Signal:** new tooling appears before the artifact works.

Intervene with:

- ask what is strictly necessary for this sprint's criterion
- keep infrastructure ideas in backlog
- prefer stdlib before library, library before framework
