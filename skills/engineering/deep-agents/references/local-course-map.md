## How to Use These Materials

1. Read the official docs first for the current contract.
2. Use the module summaries to explain the concept in simpler language.
3. Use notebooks when the user wants a concrete example or a teaching artifact.
4. If a notebook API disagrees with current docs, treat the notebook as a historical example and update it before reusing the code.
